# Posto

Posto is a personal email client for Linux. It is open source and built for
one person's own mailboxes. It reads Fastmail, Proton Mail and Gmail
accounts into one desktop window and one command-line tool, with a local
cache and an optional sorting step for new inbox mail.

Posto is not a hosted service. There is no Posto server, no account to
create and no data kept anywhere other than the computer it runs on. The
Gmail connection exists so that the person who installed Posto can read
and manage their own Gmail account from it.
